# シフト作成Webアプリ

Google スプレッドシートと Apps Script で動くシフト表作成アプリです。期間や休業日、従業員、業務を登録してシフトを生成し、一覧表で編集して印刷できます。

このリポジトリに実際の従業員・会社のデータは含めていません。最初は新しいテスト用スプレッドシートにつないで動きを確認してください。

## できること

- 期間、業務間隔、会社休業日を設定
- 従業員、業務、休暇希望をもとにシフトを生成
- 業務分類ごとの目標回数を設定し、割り当てに関する警告を表示
- 一覧表のセル編集、固定、固定の一括解除
- 固定・解除の操作を一つ前に戻す／一つ次に進める
- スマートフォンとデスクトップで一覧を表示し、A4横・白黒で印刷

生成結果は自動割り当ての案です。警告や空欄が残る場合があるため、運用前に内容を確認してください。

## ファイル

- `Code.gs` — シフト生成とスプレッドシート操作
- `WebApi.gs` — Webアプリから呼び出す処理
- `Index.html` — 画面

## 用意するもの

- Google アカウント
- 空の Google スプレッドシート
- Google Apps Script を開けるブラウザー

まずテスト用の空のスプレッドシートを作り、次の名前でシートを用意します。名前はコード内で使うため、表記を変えないでください。例の名前や業務はすべてダミーです。

| シート名 | 入力する内容 |
| --- | --- |
| `従業員` | A1=`名前`、B1=`区分`、C1=`空白禁止`。2行目以降に `従業員A / 午前 / FALSE`、`従業員B / 午後 / FALSE` などを入力します。C列は任意です。 |
| `業務` | A1は見出し、A2以降に `業務1`、`業務2` のような名前を入力します。 |
| `設定` | A1=`開始日`。B1に開始日、B2に終了日、B3に業務間隔（日）を入力します。会社休業日はB5以降に日付セルで入力します。 |
| `フォーム回答同期（初回許可）` | A1行に `タイムスタンプ`、`氏名`、`休暇希望日` の列を用意します。フォームを使わない場合もタブは作成してください。 |
| `業務分類` | A1=`業務`、B1=`分類`。業務名と `区分1` または `区分2` を登録します。 |
| `回数設定` | 空のタブを作成します。メニューからひな形を作ると、サンプル値が入ります。 |
| `シフト表`、`警告` | 空のタブを作成します。アプリが結果を書き込みます。 |

従業員の区分には `午前` または `午後` を指定します。フォーム回答は `氏名` と `休暇希望日` の列を読みます。同じ人の回答が複数ある場合は、最後の回答を使います。休暇希望日は日付セル、または `10/5, 10/13` のような月/日形式にします。

Google フォームを使う場合は、回答先をこのスプレッドシートに設定し、回答タブを `フォーム回答同期（初回許可）` にします。質問名に対応する列見出しも `氏名` と `休暇希望日` にそろえてください。

回数設定を使うときは、登録したすべての業務に `業務分類` を設定します。回数設定の「区分1」と「区分2」の目標回数の合計は、その行の出勤日数と一致させてください。ひな形の数値は例なので、実際の勤務日数に合わせて調整します。

## Apps Script の設定と公開

1. スプレッドシートで「拡張機能」→「Apps Script」を開きます。
2. `Code.gs` と `WebApi.gs` を作り、`Index` という名前の HTML ファイルを追加します。それぞれ同名のリポジトリファイルの内容を貼り付けて保存します。
3. Apps Script エディターから `setupWebAppConnection` を一度実行し、Google の認証画面を許可します。この関数は、開いているスプレッドシートのIDをこの Apps Script プロジェクトの設定に保存します。別のIDがすでに登録されている場合は上書きしません。
4. シートを再読み込みし、「シフト」メニューから「ひな形作成/更新」と「回数設定ひな形作成/更新」を実行します。業務分類と回数設定を入力し、設定の期間・休業日も確認します。
5. Apps Script の「デプロイ」→「新しいデプロイ」→「ウェブアプリ」を選びます。実行するユーザーとアクセスできるユーザーを決めてデプロイし、表示されたURLを開きます。

ウェブアプリは接続先のスプレッドシートを読み書きします。「次のユーザーとして実行」を自分にする場合、アクセスを許可した人の操作は自分の権限でシートに反映されます。共有相手を必要な人に絞り、まずダミーのスプレッドシートで生成・編集・印刷を確認してください。

スマートフォンの Google スプレッドシートアプリからチェックボックスで操作する機能もあります。必要な場合だけ、`設定` シートのD1:E10が未使用であることを確認してから `installMobileSupport` を一度実行してください。この関数はD1:E10に操作欄を作り、編集トリガーを追加します。
